# Triage Labels

スキルは、トリアージの役割を 5 つの標準的な名前で扱う。このファイルは、その役割を、このリポジトリの Issue tracker で実際に使うラベルの文字列に対応づける。

| mattpocock/skills のラベル | このリポジトリのラベル | 意味                                           |
| -------------------------- | ---------------------- | ---------------------------------------------- |
| `needs-triage`             | `needs-triage`         | 編集者による評価が必要                         |
| `needs-info`               | `needs-info`           | 報告者からの追加情報を待っている               |
| `ready-for-agent`          | `ready-for-agent`      | 仕様が固まっており、AI エージェントが自律して実装できる |
| `ready-for-human`          | `ready-for-human`      | 人間による実装が必要                           |
| `wontfix`                  | `wontfix`              | 対応しない                                     |

スキルが役割に言及したとき(例: 「エージェントが自律して実装できるラベルを付ける」)は、この表の対応するラベルの文字列を使う。

実際に使うラベルの名前が違う場合は、「このリポジトリのラベル」の列を書き換える。
